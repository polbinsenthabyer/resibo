# Resibo visual sources

Original exports here were generated in the Magnific `pol` project. Web copies
in `client/public/` have metadata removed and use smaller canvas dimensions;
the original shapes remain in the SVGs. The icon set cost 4,875 credits
(13 SVGs at 375 credits each). The earlier logo iterations are recorded in the
project plan and vault.
