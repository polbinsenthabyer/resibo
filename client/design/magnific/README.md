# Resibo visual sources

The receipt-and-arrow logo was generated in the Magnific `pol` project at the
owner's request. Its [selected creation](https://www.magnific.com/app/creation/aFnQXCMfSh)
is preserved as `resibo-logo-original.svg`, alongside the transparent concept
PNG. The cropped web copy is `client/public/resibo-logo.svg` and supplies the
header and favicon.

UI icons use Lucide React. Magnific is only used again when the owner explicitly
requests it.
